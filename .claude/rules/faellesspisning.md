# Fællesspisning (`faellesspisning.html`/`faellesspisning.js`/`faellesspisning.css`) — communal-meal sign-up

One row per person (alphabetical by Navn, Danish collation — `localeCompare(..., 'da', {sensitivity:'base'})`), one column per rehearsal/performance day, a checkbox = "eating that day", plus a per-day headcount/food-preference summary. Revyst-level page; private data in `FAELLESSPISNING_DATA_DIR` (`/data/faellesspisning`). Replaced the old generic "Ark" page.

- **Attendance default (opt-out/opt-in)**: each row carries its own `attendanceMode`, stamped by the server at creation (`faelles_upsert_row` create, `faelles_sync_connection` new rows) from the document's `attendanceMode` (`faelles_attendance_mode()`; missing = `'out'`, so every row from before the setting is opt-out). `'out'`: a day defaults to **checked** from the row's own `createdAt` date onward, unchecked before. `'in'`: every day defaults to unchecked. Switching the setting only affects rows created afterwards. `row.dayOverrides` (`{dayId: bool}`) stores only deviations; a row without it reduces to the default. `faellesDayDefault(row, col)`/`faellesIsDayChecked(row, col)`/`faellesRowMode(row)` are the source of truth (server: `faelles_validate_day_overrides()`). An unsaved draft row previews the sheet's current mode against today. Overrides for removed/hidden days are left alone.
- **Notice** (`faellesBuildNotice`): two short lines centered in the sheet card's toolbar. The bold `notice`, default "Madtilmelding lukker kl. <closeTime> på dagen" while never set (`faelles_notice()`; "kl. 14" for a whole hour, "kl. 14.30" otherwise, so it follows the closing time; a stored notice never does), and under it the plain, muted `subNotice`, default "(I bliver automatisk tilføjet madarket gennem tilmeldingsformularen)" (`faelles_sub_notice()`); `''` = that line isn't shown. Boss/admin edit each in place (inline field style, saves on blur/Enter, Escape reverts) via `faelles_set_notice`, which changes only the keys sent; plain text below boss.
- **Closing time** (`closeTime`, `"HH:MM"` Danish time, default `14:00`, `faelles_close_time()`): a day column closes at that time on its own date and stays closed on every later date. Only **admin** sets it, via the "Lukker kl. HH:MM" menu button top-left in the sheet card's toolbar (`faellesBuildCloseTimeButton`, the shared `siteOpenTimePicker` quarter-hour list, "Ingen tid" ignored) → `faelles_set_close_time`. Every level below admin, boss included, can't change a closed day's checkbox. Client: `faellesIsDayClosed(col)` (Copenhagen time via `Intl`, `faellesCopenhagenNow()`), `faellesCanEditDay(col)`, disabled checkboxes, muted `.faelles-col-closed` headers, a re-check in the `change` handler, and a 30 s `faellesRefreshDayLocks()` that re-locks in place (by `data-day-id`) when the page stays open past the closing moment. Server: `faelles_upsert_row` (gets `$level`) refuses any added/removed/flipped override on a closed day with `403 day_closed` (`faelles_touches_closed_day()`; day dates from `extraDays` + `data/calendar.json` read from disk, unknown ids are not locked). Navn/Madforbehold stay editable.
- **Madark / Oversigt toggle** (revyst+, `faellesBuildViewToggle`): a two-button `.site-segmented` at the right of the sheet card's toolbar switches between the table and satyr's per-day overview (`faellesBuildSummaryCard`, built from the same `faellesState`, so no extra read); the choice is per browser in `localStorage` `matrevy-faelles-view` and survives every `faellesRender`. Satyr gets the overview without the toggle.
- **Boss Box** (`faellesBuildBossBox`, boss/admin, the shared `.site-boss-box`: last on the page, below the sheet or overview, open on every load — `faellesBossBoxOpen` is in-memory only): "Forbind til formular" (explanation, "Forbundet til: …"/"Ikke forbundet", Forbind/Skift forbindelse → `faellesOpenConnectModal`) and "Tilmelding for nye rækker" ("Nye rækker er" dropdown Automatisk tilmeldt alle dage / Ikke tilmeldt nogen dage → `faelles_set_attendance_mode`, toast on save).
- **Two fixed columns**: Navn and Madforbehold (`FAELLES_FIELDS`). Boss/admin drag a grip on either header's right edge to resize it (`faellesColumnResizer`, Bandet's recipe; double-click resets), saved for everyone as `columnWidths` `{navn?, madforbehold?}` px via `faelles_save_column_widths` (full replace, 40-1000). The table keeps its auto layout: a width is applied as `--faelles-w-<id>` + `.faelles-sized-<id>` on the table (`faellesApplyColumnWidths`), pinning every cell of that column; header/summary labels sit in `.faelles-clip` so their text can't hold a narrowed column open. A truncated Navn/Madforbehold shows its full text in a tooltip.
- **Rows**: any revyst+ can edit any existing row (shared passwords, no per-user identity), but only boss/admin add (the "+" row; `faelles_upsert_row` without `rowId` is checked for boss at dispatch) or delete rows (the ✕ column); revyster get neither, and rows normally arrive through the connected form. `faelles_delete_row` is idempotent.
- **`faellesApi(action, body)`** mirrors `formsApi`/`budgetApi`.
- **Single document**: `faellesspisning.json` = `{rows, connection, extraDays, hiddenDays, attendanceMode, notice, subNotice, closeTime, columnWidths, updatedAt}`; `faelles_extra_days()`/`faelles_hidden_days()` back-fill `[]` for older documents.
- **Row-granular, live writes**: `faelles_mutate()` (flock'd) backs `faelles_upsert_row`, which **merges** sent `answers` keys and **full-replaces** `dayOverrides`. No batched draft: fields commit on blur, checkboxes on change; `row._inFlight` chains same-row commits (no duplicate creates); each request is built when its turn comes, and only the reply to the latest edit (`row._editSeq`) may overwrite the row, so quick successive edits are never dropped. `faellesSavesPending` drives a `beforeunload` warning and `siteRegisterUnsavedCheck`.
- **Day columns** = Kalender's `ove`/`forestilling` events (read live, minus `hiddenDays`; `faellesCalendarOverride` mirrors Kalender's own override so a new event shows immediately) + the document's own `extraDays`, filtered to the current rolling half-year (`faellesCurrentHalfYearRange()`: Jan–Jun or Jul–Dec of today), sorted by date, labeled `d/m` with the event title as tooltip (`faellesShowFieldTooltip`). Not keyed off `currentProductionFolder` (a jubilee revy can run alongside).
- **Boss adds a sheet-only day** via the "+" after the last column (`faellesOpenQuickAddDateModal` → `faelles_add_day`, into `extraDays`; never touches Kalender). **Every column is removable** (bottom-row "✕", `faellesOpenDeleteDayConfirm`): an extra day is deleted (`faelles_delete_day`), a calendar day is only hidden from this sheet (`faelles_hide_day` → `hiddenDays`; no un-hide UI).
- **Summary** is client-side: headcount per day, and an "ⓘ N" button per day opening a modal of only the attendees with a food preference (`faellesOpenPreferencesModal`).
- **Server actions** (`$FAELLES_ACTIONS`): revyst — `faelles_read` (also lazily syncs), `faelles_upsert_row` (creating a row: boss); boss — `faelles_delete_row`, `faelles_add_day`, `faelles_delete_day`, `faelles_hide_day` (calendar ids validated as bounded strings), `faelles_save_connection`, `faelles_set_attendance_mode` (`mode: 'in'|'out'`), `faelles_set_notice` (`notice`/`subNotice`, ≤200 chars each), `faelles_save_column_widths`; admin — `faelles_set_close_time` (`closeTime`, `HH:MM`).
- **Connect to a Formularer form** (boss; from the Boss Box; `faellesOpenConnectModal`): pick a form and which fields answer Navn and Madforbehold (reuses `forms_admin_list`/`forms_admin_read`). Persistent: `faelles_save_connection` stores `{formId, navnFieldId, madforboholdFieldId, formTitle, syncedCount}` (the key's misspelling is real) and syncs; every `faelles_read` runs `faelles_maybe_sync()` — a lock-free response-count check that only locks and reconciles when there's new data. Synced rows carry `source: {formId, responseId}` and are updated in place (only Navn/Madforbehold; `dayOverrides` untouched); `faelles_forms_answer_to_text()` stringifies any field type. Disconnecting keeps synced rows; a hand-deleted row reappears on the next sync while its response exists (one-way). Disconnect confirms via `faellesOpenDisconnectConfirm`, stacked on the connect modal.
- **Buttons**: the Boss Box's Forbind is `.btn-small` (no "Opdater" — a page refresh does the same); "+"/"✕" affordances are `.site-icon-btn` (`.site-add-plus`, `-danger`, `-sm` for the day columns' ✕); modal buttons are `.site-btn-*`; deletes confirm with a styled modal, never `confirm()`. The sheet is a `.site-sheet` that scrolls with the page (header row via `siteStickyHead`), Navn sticky sideways.


**Satyr view**: `faellesRenderSummaryView()` only: the bold notice, then one horizontal card per day from today (date + headcount left, grouped Madforbehold right, fewest words first, four columns, one below 719px). No names; data from the satyr-level `faelles_summary` action, which strips every row to attendance + Madforbehold.
