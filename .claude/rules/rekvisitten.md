# Rekvisitten (`rekvisitten.html`/`rekvisit.js`/`rekvisit.css`) — the prop crew's sheets

Replaces the prop crew's yearly files with five tabs (`REKVISIT_TABS`, active tab in `matrevy-rekvisit-tab`, styled like Ninjas'): **Rekvisitter**, **Brændimprægnering** (key `braend`), **Hvem, hvornår?**, **Indkøbsliste**, **Bosser** (boss/admin only) — each a Kostumetinder-style sheet (a page-scoped generalisation of `kostume.js`: blur-commit cells chained on `row._inFlight`, handle-drag rows, renamable/resizable/removable columns, custom text columns, click-to-cycle pills). Revyst-level page under Redskaber. Private data (names) in `REKVISIT_DATA_DIR` (`/data/rekvisitten`): `<folder>/rekvisitten.json` = `{sheets: {rekvisitter, hvem, indkob, braend, bosser}, updatedAt}` (a `regnskab` sheet from the removed Regnskab tab may remain, unused); a row sheet is `{rows, columnLabels, columnWidths, customColumns, hiddenColumns}`, a missing sheet reads as 10 blank rows with deterministic ids (`rekvisit_default_id()`). Online-only.

- **Per revy, with a picker** (`rekvisitRevyOptions()`, Bandet's picker minus instances: Arkiv years + the current production, choice in `matrevy-rekvisit-revy`). Every action takes `folder` (`rekvisit_folder_from_body()`); reads work on any revy, but **writes below boss only reach the current production** (`403 read_only`, checked at dispatch; `rekvisitCanEdit()` mirrors it and renders older years read-only). `MatRevy_2025` was imported once from the 2025 spreadsheets/documents.
- **Columns are defined twice** — `rekvisit_sheet_defs()`/`rekvisit_status_values()` (server) ↔ `REKVISIT_SHEETS`/`REKVISIT_STATUSES` (client); keep them in sync. Pills: Brændimprægneret (- light red / En side light green / Begge sider! green / Skal ikke light green; values `''`/`enside`/`begge`/`skalikke`, a legacy `ja` reads as `begge`), Indkøbsliste Købt? (- / Ja), Bosser En dag/To dage (- / Tjek green; `''`/`tjek`).
- **Brændimprægnering (`braend`) has no rows**: it lists Rekvisitter's named rows (Rekvisit read-only) and edits their own free-text `braendNote` ("Kommentar"), the `braend` pill and, right of it, its own progress bar `braendProgress` ("Status", independent of Rekvisitter's `progress`, back-filled 0; its own "Samlet status" averages it) via `sheet:'rekvisitter'` (`rowSheet` in `REKVISIT_SHEETS`); `sheets.braend` only stores its titles/widths. Rekvisitter itself shows neither.
- **Bosser (`bosser`, tab `level: 'boss'`, `rekvisitVisibleTabs()`) has no rows**: like braend, it lists Hvem, hvornår?'s named rows (`nameKey: 'navn'`, Navn read-only) and edits their `bossEnDag`/`bossToDage` pills and free-text `bossNote` ("Noter") via `sheet:'hvem'`; `sheets.bosser` only stores titles/widths/note. **Server-enforced**: below boss `rekvisit_read` drops `sheets.bosser` and the `rekvisit_boss_keys()` fields from hvem's rows, and the dispatch block 403s any `sheet:'bosser'` write or an upsert row carrying a boss key. A remembered Bosser tab falls back to Rekvisitter for a lower (or "vis som") level. Deleting a person on Hvem, hvornår? deletes their Bosser marks too (same row).
- **Rekvisitter row colours**: `rowColor` (`''`/`green`/`orange`/`red`, a status field; `REKVISIT_ROW_COLORS` ↔ `rekvisit_status_values()`) tints the whole row (`.rekvisit-row-color-*`: `--success-tint`/`--warning-tint`/`--danger-tint`, opaque so the sticky column matches). A click (not a drag) or Enter/Space on the ⠿ handle opens a `.site-field-pop` menu (Grøn, Orange, Rød, Ingen farve); saved rows only. Shown on Rekvisitter only (`rowColors` in `REKVISIT_SHEETS`), not on Brændimprægnering.
- **Rekvisitter starts with 50 rows**: `rekvisit_sheet()` pads a rekvisitter sheet with fewer once (blank rows, ids from their slot, `rekvisit_default_id(…, 'rekvisitter/pad<i>')`) and sets `minRowsApplied`, stored with the next write, so later deletions stick.
- **Rekvisitter's Status** (rightmost, `stayRight`, not removable): `progress` is an int 0-100 (field type `'progress'`), set with a draggable bar (`rekvisitProgressBar`, steps of 5, arrow keys/Home/End, commits on release) whose fill fades red → orange → green (`rekvisitProgressColor`); rows without one are back-filled from the old `status` pill on read (Færdig 100, I gang 50, else 0; the old `status` stays in the file, unused). "Samlet status" top right of the card is the plain average over named rows, live while dragging (`rekvisitRefreshTotalProgress`). Rekvisitter has a coloured band row above the titles (`groups` in `REKVISIT_SHEETS`: Instruktør over the first four columns, Rekvisit over the rest + custom columns + Status), whose titles boss/admin rename in place (`groupLabels` on the rekvisitter sheet, boss `rekvisit_set_group_label`). Every sheet has a line between all columns, its first column (+ handle) is sticky when scrolling sideways (`rekvisitStickyCell`), and its header rows follow the page scroll via the shared `siteStickyHead()` (site-utils.js; the wrap's `overflow-x` rules out CSS `sticky top`, so it shifts each `thead th` with `translateY` to just under the site header).
- **Hvem, hvornår?**: Navn + one column per **date** — Kalender's `ove`/`forestilling` dates (same-date events merged, `endDate` expanded, like `koordLokalerDays()`) in July–December of the folder's year (`rekvisitDayRange()`), minus `hiddenDays`, plus `extraDays` (`{id, date, title}`; "+" in the header). ✕ deletes an extra day / hides a Kalender date (`rekvisit_add_day`/`_delete_day`/`_hide_day`). A row's cells are `days: {YYYY-MM-DD: text}` (merged per key, `''` clears); "x" = not here (red; a legacy "1" counts too), other text = partial (amber); footer "Til stede".
- **Amounts** (Indkøbsliste's prices) are free text parsed by `rekvisitParseAmount()` ("1.061,70", "130 kr") for the footer sums.
- **Server actions** (`$REKVISIT_ACTIONS`, all revyst + the folder rule; row/column actions take `sheet`): `rekvisit_read`, `rekvisit_upsert_row`, `rekvisit_delete_row` (idempotent), `rekvisit_reorder` (permutation or `409 stale_rows`), `rekvisit_save_columns`, `rekvisit_save_column_labels`, `rekvisit_save_column_widths`, `rekvisit_set_group_label` (boss; `{key: 'instr'|'rekv', label}`, `''` = default), `rekvisit_set_note` (boss; the text line above a sheet, stored per sheet as `note`, `''` = none, missing = the `REKVISIT_SHEETS` default; edited in place on the page), `rekvisit_add_day`, `rekvisit_delete_day`, `rekvisit_hide_day`. `rekvisit_mutate()` = flock'd copy of `kostume_mutate()` per sheet; hoisted functions, no consts (dispatched early).
