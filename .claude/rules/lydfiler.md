# Lydfiler (`lydfiler.html`/`sangere.js`/`sangere.css`) — the singers' practice audio

Sound files for the singers, capped at **500 MB**. Revyst-level page under Redskaber, fully open at revyst+. Was called Sangere: the page file and URL are `/lydfiler` (`/sangere`, `/sangere.html` 301 there in `apache-site.conf` and `dev-router.php`), but **everything internal keeps the `sangere` name** (`sangere_*` actions, `SANGERE_DATA_DIR`, `sangere.json`, `js/sangere.js`, `css/sangere.css`, `sang` prefix, `#sangere-root`). The upload queue, usage bar and signed downloads are page-scoped copies of Teknikken's. **The server shares Teknikken's store code**: `teknik_stores()` describes both stores (dir, document, quota, zip title, `needsUploader`, `pausable`) and `$GLOBALS['TEKNIK_STORE']` picks one; `$SANGERE_ACTIONS` (`sangere_read`, …, admin `sangere_clear_all`) selects `sangere` and runs the matching `teknik_*` handler. Data in `SANGERE_DATA_DIR` (`/data/sangere`: `sangere.json` + `files/` + `uploads/`), never archived or mirrored, excluded from the restic backup. Signed download links carry the store as an `s` claim inside the HMAC (missing = teknikken).

- **One "Upload lyd-filer" button** (or files dragged in from the desktop): audio only (`SANG_AUDIO_EXTS`; anything else skipped with a toast). Like Bandet's sheet music, the modal asks a **required name per file** (empty, sent as `<navn>.<ext>`, shown without the extension) plus "Upload til". No Afsender (`needsUploader: false`, so `uploadedBy` is `''`).
- **Folders as Bandet-style cards** (`sangBuildCard`/`sangBuildFileRow`, page-scoped copies of `bandBuildFolder`/`bandBuildFileRow`; CSS copied from band.css's Noder block as `.sang-folder*`/`.sang-file*`): every folder is a flat card in one alphabetical grid under Filer (3 columns, 1 at ≤719px), no sections and no sub-folders. Folders are made by hand ("+ Ny mappe"); nothing is linked to Bandet or Manus. A card's `.site-collapse` head shows the name and file count and opens to its files + a bar with "Upload filer" centred and a pencil in the right corner. The pencil opens "Rediger mappe" (`sangOpenEditFolderModal`: Navn, Slet bottom left, Gem right); Slet asks "Er du sikker…?" (`sangConfirmDeleteFolder`) and deletes the folder with all its files. No per-folder zip button (only "Download alt"). An "Uden mappe" card appears while loose top-level files exist (no uploads to it).
  - Card keys (`sangCards()`): `f:<folderId>` and `root`; the open set in `localStorage` `matrevy-sangere-open` and the "Upload til"/"Mappe" dropdowns use them (`sangResolveTarget()` → folder id). File rows drag onto another card to move (`sangWireCardDrop`); desktop files dropped on a card upload there, elsewhere on the Filer card open the modal without a folder chosen.
  - The server keeps the store flat: `sangere_create_folder` refuses a `parentId`, and `sangere_read` runs `sangere_flatten()`, a one-time migration from the old tree (files move to their top-level folder, sub-folders are dropped; a no-op without nesting). The old Manus-based song-folder seeding (`songFoldersFor`) is gone.
- **"Guide til øvetracks med Moises.ai"** card below Filer (`sangBuildGuide()`), laid out like Koordinator's "Guide til Arkivering": intro, then a heading + paragraph per step. Boss/admin edit it in place like Forside's Bosser card (pencil → title, intro, steps with heading + text, drag handle to reorder, "+"/✕; check mark saves via boss `sangere_set_guide`, a full replace stored as `guide` in `sangere.json` and returned by `sangere_read`). `SANG_GUIDE` in `sangere.js` is shown until it's saved once; `sangere_clear_all` keeps it, so it carries over between revys. Plain text: line breaks kept, a URL becomes a link (`sangLinkify`). It renders into its own `#sangere-guide`, outside `sangRender()`'s root, so uploads finishing never redraw it mid-edit. A YouTube/Spotify → mp3 feature was considered and dropped (YouTube blocks datacenter IPs, Spotify is DRM-protected), so the guide points to an external converter site instead.
- Uploads are closed while no revy is active (`uploads_closed`); no boss pause (`pausable: false`). Koordinator's **Afslut revyen** empties it (folders included) (`sangere_clear_all`) right after Teknikken.
- Clicking a file opens it inline (plays in the browser) for mp3/m4a/wav/aac/ogg/flac (`teknik_inline_types()` ↔ `SANG_INLINE_EXTS`).
