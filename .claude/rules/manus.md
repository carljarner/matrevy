# Manus (`manus.html`/`manus.js`, `data/manuscripts.json` + `data/scenes.json`/`cast.json`)

**Upload pool**: any revyst+ submits a sketch/song via the append-only `manuscripts_create` action. The server slugifies the title, writes `archive/<currentProductionFolder>/submitted/<slug>.{pdf,tex}` and appends the record. The revyst-level `manuscripts_update` ("Opdater") replaces a submission's files while it's still in `submitted/`. `config.json`'s `sketchUploadsClosedForRevyst`/`songUploadsClosedForRevyst` close uploads per type (boss/admin toggles in the page's Boss Box card; `MANUS_UPLOADS_CLOSED_KEYS`), and `pdfLinksVisibleToRevyst` ("Revyster kan se manus") shows the PDF quick links to revyster and gates the current production's Manus pill on Arkiv (`archiveManusHidden`) and the GitHub mirror's hidden view (above). A second toggle, `rolesVisibleToRevyst` ("Revyster kan se roller", locked while manus is off; turning manus off turns it off too), reveals the names: until it's on, revyster (`manusRolesVisibleToRevyst()`) get no Rollefordeling button, the Manus dropdown only offers "Manus (uden navne)" (`anonym/manus.pdf`), a chosen pool row's title opens its `anonym/` scene PDF (`manusPoolAnonymPdfPath`, a toast if it hasn't been generated yet, never the named one), Arkiv's pill links that copy (`archiveManusLink`), Øveplan and Ninjas list no scenes, and GitHub shows the redacted view. Flipping either toggle asks first (`manusConfirmPublish`/`manusConfirmPublishRoles` on `manusConfirmToggle`). While it's on, the revyst pool columns split per type into "Sange/Sketches (valgt)" (open) above "(ikke valgt)" (closed), chosen = `manusSubmissionIsSelected()`; at ≤719px the stacks become `display: contents` so the order is Sange (valgt), Sketches (valgt), Sange (ikke valgt), Sketches (ikke valgt). Two delete paths: the pool's "Fjern" (boss, `manuscripts_remove`, one id) removes only the record and leaves the files; "Slet" in Vælg scener calls admin-level `manuscripts_delete`, which deletes the pdf/tex **and** the record. **"ny" tag**: a pool row this browser sees for the first time gets an orange "ny" before its title (`manusComputeNewIds()`, once per page load, `localStorage` `matrevy-manus-seen` = `{folder, seen: {id: firstSeenMs}}`); it stays on every reload within an hour of first seen, then disappears. A first visit or a new production folder tags nothing, and your own uploads are marked seen at once (`manusMarkSeen`). **"Sang (fisk)"** stores an ordinary `type:'sang'` submission plus `fisk: true` — a song in every respect; the flag only affects selection-stage lists (pool, Vælg scener, Stemmeark/Indtast point), which list fisk songs last, alphabetically, below a divider, as `Fisk: Title` (`manusSortWithFisk`/`manusRowIsFisk`, the latter resolving a graduated scene back via `sourcePdf`).

**Duration default from `\eta{}`**: the upload/Opdater modals parse the `.tex`'s `\eta{}` (`extractTexDuration`/`parseEtaDurationMinutes`, tolerant of prose like "$2:56$ minutter" or "$3-4$ minutter") and send it as `duration`, which seeds the row's duration in Vælg scener. Rows without one are backfilled from their `.tex` (fetched same-origin, `MANUS_TEX_RAW_BASE = '/'`) by `manusImportFromTex`. Boss/admin edit it freely: a scene's duration is saved with the scene, a pool row's (not in an act, so not in `scenes.json`) by Gem via the boss `manuscripts_set_durations` action (`{id, duration}` pairs, only rows whose duration differs from `_baseDuration`) onto the submission in `manuscripts.json`.

**Udvælgelse card** (selection stage, before scenes exist): **Stemmeark** ("Hent stemmeark" prints voting sheets), **Indtast point** (per-browser points 0-10 per sheet in `localStorage` `matrevy-manus-points`, results as Tabel or Boxplot, `matrevy-manus-points-view`; `manusPointsStats` gives averages), **Aktfordeling** and the **Vælg scener** button.
- **Aktfordeling** (`openAktTagModal`/`manusPrintAktCards`, per type Sange/Sketches; `localStorage` `matrevy-manus-akt-tags`, keyed by submission `id`, never synced): three tabs — **Scener** hand-picks submissions (best point average first, never auto-picked), **Kategorier** edits labels, **Stil & Tema** tags each picked one with one **Stil** (→ card shape: rectangle/rounded/hexagon/rhombus/triangle/octagon/fish, 8:3 on the printed cards) and any number of **Tema** labels (→ fill colour: the shape's right half, one stripe per theme; the left half stays white/grey). Stil labels are per type (Sange: Sang/Rap/Andet/Fisk; Sketches: Kort/Lang/Serie/Musik), Tema labels one shared list (`store.themes`, seeded Kridt/Whist/Instruktor). Removing a label in use warns with the affected titles. Udskriv prints a legend + 3-up cut-out cards (inline SVG via `manusBuildAktShapeSvg`; title, `avg. X, time. Y min`; untagged sketch cards light grey, songs white). Unrelated to the Main Manus View's own Aktfordeling tab despite the name.

**Custom print** (a group in the Udvælgelse card between Aktfordeling and Vælg Scener; `openCustomPrintModal(type)` per Sange/Sketches): tab **Scener** picks scenes (split into "(valgt)"/"(ikke valgt)" with a "Vælg alle" toggle each once any row of the type is selected), tab **Antal** sets copies per scene (default = number of roles: `manusCastCount`, else counted from the `.tex` via `extractTexRoles`, else 1; only edited values are stored). Per browser in `localStorage` `matrevy-manus-custom-print`, keyed by row `uid`. **Udskriv** (bottom right, `manusCustomPrint`) fetches each scene's PDF (`manusRowPdfPath`), then merges them alphabetically with each repeated N times using **pdf-lib vendored at `js/vendor/pdf-lib.min.js`** (lazy-loaded by `manusLoadPdfLib()`), behind a centered progress box (`manusOpenPdfProgress`, z-index 220: "Henter scener" → "Samler PDF… x af N sider", Annuller). Only once it's built does it open in a new tab; if the browser blocks that (the click's user activation has expired), the box offers "Åbn PDF". Built in memory only — never uploaded or stored; the blob URL is revoked after a minute.

**Main Manus View** (boss/admin): five tabs (active tab in `localStorage` `matrevy-manus-tab`) — **Scener** (which pool/existing scenes are in the revy, via the "Vælg scener" overlay of click-to-toggle rows, batched into one save; the tab lists each type as "Sange/Sketches (valgt)" (open) above "(ikke valgt)" (closed) like the revyst pool, by the draft row's `selected`, open/closed state kept across re-renders in `manusSelectColExpanded`), **Aktfordeling** (drag rows into one of 4 acts or "Ikke placeret"), **Rollefordeling** (per-scene cast via a monospace textarea of `\role{<code>}[<name>] <description>` lines, parsed only on "Opdater roller"), **Manus** (per-scene LaTeX body, a plain textarea — the content genuinely is LaTeX), **Program** (below, auto-saved). The first four share one flat draft row list (`manusDraft.rows`), built once per render and rebuilt only after a successful save. `manusRowScene(row, act, idx)` is the single source of truth for a row's save-shaped scene, so display and save can't drift.
- Role classification (`ROLE_CATEGORIES`/`classifyRoleCode`/`classifyOrKeep`) lives in `schedule.js` and is duplicated verbatim in `manus.js` and `scripts/generate-pdfs.js`. **Always call `classifyOrKeep`, never `classifyRoleCode` directly** — a role can already be a category string, and re-classifying matches against its spelling (`"Koreograf"` starts with `K` → Kor).
- **Cast list** (a "Cast list" header with a Rediger button at the bottom of Rollefordeling's last act column, `renderCastListSection`/`openCastListModal`): `cast.json` is **exactly the names in the scenes' `\role{code}[<name>]`**, plus the Sangboss (below). `manusMergeCastRoster()` rebuilds it on every Gem: roster order, new names at the end, whole entries kept so flags survive, unused names dropped (except the Sangboss). The modal lists each draft name once, alphabetically, with:
  - its scene count
  - a "Ligner …" near-duplicate hint (`manusCastNamesLookAlike`: same name ignoring case/accents, a 1–2 letter edit, or a lone first name)
  - a **Revyst** checkbox (on = a real person; off = `placeholder: true`). It saves live via the boss `manus_set_cast` action (`{name, placeholder}`); a name not saved yet keeps the choice in `draft._castFlags` until Gem.
  - **Omdøb**: replaces the name in every draft row's `cast` and records `draft._castRenames` (old entry's place/flag go to the new name), so it saves with Gem.
  - A **Sangboss** line above the table (`renderCastListSangboss`): a free-text name with cast-name suggestions (`manusWireNameSuggestions`), saved live on blur/Enter via the boss `manus_set_sangboss` action (`''` = nobody). It flags that roster entry `sangboss: true` (appending one if the name is in no scene; the previous Sangboss entry is dropped when no scene uses it), and `manusMergeCastRoster()` keeps a flagged entry on Gem, so the Sangboss is in Fravær and Øveplan. The Sangboss PDF in `manuskripter/` is unrelated (every song, whoever is cast).

  `castIsPlaceholder(entry)` (explicit `placeholder`, else `CAST_PLACEHOLDER_RE`: Skuespiller/Danser/Sanger/Rapper/Revyst/Statist(er)/Ninja/Kor/… plus an optional number) is duplicated in `manus.js`, `schedule.js`, `koordinator.js` and `generate-pdfs.js`. Non-revyster get no `manuskripter/` PDF and aren't in Manus's dropdown. In Øveplan they're dropped from `state.allCast` and never count as a clash (`schedIsPlaceholderName`). Koordinator's Fravær suggestions skip them too.
- **Videoer & Bandsange**: the only way to get a video/band-jingle scene into the pipeline (no upload path; `manuscripts.json` is sketch/song only). A manual row (`origin:'manual'`) is made via a modal with the same `\title{}/\author{}[/\melody{}]` header plus Roller/Manus textareas. `manusRowIsManualMedia(row)` (checks `types`, since a reloaded row is only detectable that way) filters them out of Rollefordeling/Manus/Stjerneark and out of Øveplan (`schedulable:false`).
- **`MANUS_POOL_ACT_CODE = 'pool'`**: a still-unplaced manual video/bandsang row survives a save in this reserved pseudo-act (pool sketches/songs persist through `manuscripts.json` instead). It's excluded from `draft.acts`, re-attached whenever the acts payload is rebuilt, and skipped by `generate-pdfs.js`.
- **Save** (`manusSaveMain()`) **merges before it writes**, so several people can edit at once (full design and status in `plans/autosave.md` → Manus): `manuscripts_sync_selection` for pool rows whose selection changed in this tab (`row._baseSelected`), then `manus_read` (live `scenes.json`/`cast.json` + shas) → `manusMergeActs()` three-way merge of `draft._base` / draft / live, per scene by its permanent `uid` (`manusSceneUid()`) and per field group (Roller / Manus / Stjerneark / Titel og detaljer, plus act order) → `manusAskConflicts()` only when both sides changed the same group of the same scene → the `manus` resource with `baseScenesSha`/`baseCastSha` (a 409 `stale` re-reads and retries), then `program` if `programIsDirty()`. Not optimistic: the draft stays editable, and `manusRebaseDraft()` rebuilds it from the saved result, replaying edits made during the save. `manusResourceSaveInFlight` disables Gem meanwhile.
- **Local draft backup** (`siteDraftBackup('manus')`, `manusBackupTick()` on the 500 ms save-status poll): while the Gem tabs are dirty the whole draft (incl. `_base`) is mirrored to `localStorage`, cleared once clean. On load a backup for the current production folder is offered in a banner above the tabs (`manusRenderBackupBanner`, Gendan/Kassér; nothing is written while the offer is open). Gendan makes it the draft as-is (fresh row keys, current pool submissions) — like a tab left open, so Gem's three-way merge against the backup's own `_base` handles anything saved since. Anything that builds scene objects must keep `uid` (`manusRowScene()` sets it).
- **Stjerneark's fields** live on the draft rows only so `manusRowScene()` writes them back unchanged (`manusStarFieldsFromScene`/`manusApplyStarFields`, kept for the save shape); they're edited on the Stjerneark page (below). The draft never changes them, so Gem's merge takes whatever that page saved meanwhile, and `manusSerializeDraft` leaves star fields of saved scenes out of the dirty diff. "Generér PDF'er" flushes Program's auto-saver first.
- **PDFs** (`scripts/generate-pdfs.js`, run by the worker on "Generér PDF'er", which calls `manus_regenerate_pdfs` → flag file; it writes no data, so it builds from what's saved, not the draft. `save_manus()`'s `regeneratePdfs:true` → `[regen-pdfs]` path still exists but the page no longer uses it): reads `scenes.json`/`cast.json`/`config.json`/`archive.json`/`program.json`, composes one `.tex` per sketch/song/bandsang scene with a non-empty `scriptBody` (skips recompiling when byte-identical to the archived `.tex` and the PDF exists), and writes into `archive/<folder>/`: per-scene PDFs (`sketches/`, `songs/`), **Aktoversigt.pdf**, **Rolleoversigt.pdf** (no video/bandsang rows), **manus.pdf** (master manuscript, title page + every scene via `pdf-lib`; same filename as hand-uploaded pre-pipeline years so Arkiv's link is uniform), `manuskripter/` (one per cast member with at least one compiled scene + Sangboss when there's a song; any other PDF there is deleted, and Manus's dropdown only lists those names via `manusScenesWithPdf()`), and the Program PDFs. Every scene is also built **redacted** (`buildSceneTex(…, redact)`, each `\role{X}[name]` → `\role{X}[navn]`) into `archive/<folder>/anonym/{sketches,songs}/` plus `anonym/manus.pdf`, every run whatever the toggles (same unchanged-skip cache; a scene without names just copies its real PDF; stale files removed by `removeStaleAnonym`), for revyster and the GitHub mirror while "Revyster kan se roller" is off. Each regeneration overwrites the scene's archived `.tex` (`sourceTex`) with the composed content (minus the error markers below). Role labels use each cast entry's `roleCode`/`description` when present. Can be run locally (`node scripts/generate-pdfs.js`, needs `pdflatex`) against a local data copy.
- **Build status & errors**: every compile (each scene, Aktoversigt, Rolleoversigt, each Program section) runs even after another fails; any failure skips only the merge steps (`manus.pdf`, `manuskripter/`, the Program PDFs), so they never mix old and new pages. The run writes `{state: running|done|failed, startedAt, finishedAt, errors}` to `PDF_STATUS_FILE` (`/data/site/generated/pdf-status.json` on web-1, not web-served; `.pdf-status.json` locally). Each error is located by `buildErrorEntry()`: the `.tex` builders emit `% matrevy:part=titel|roller|manus` / `% matrevy:scene=<id>` / `% matrevy:part=medvirkende|ordliste` / `% matrevy:qr=<id>` comment lines, and walking back from the log's `l.<N>` to the nearest marker gives the scene, part and line within the manus/Program text; a "Unicode character X" error instead searches the scenes' fields for X (pdflatex reports a `\title{}` at `\maketitle`, and Rolleoversigt's `\resizebox` at the box's end). pdflatex halts on the first error per file, so one run shows at most one error per document.
- **Completion poll** (`manusPollPdfCompletion()`): `manus_regenerate_pdfs` returns `requestedAt` (server ms); every 3 s (`MANUS_PDF_POLL_INTERVAL_MS`) the page reads the boss `manus_pdf_status` action and waits for a run with `startedAt >= requestedAt`: `done` → success, `failed` → `manusOpenPdfErrorModal()` (errors grouped by cause with the documents they broke, a Danish hint per common LaTeX error, the offending line or field value, the log tail, and "Gå til scenen"/"Gå til Program" opening the scene's Manus/Rollefordeling/video editor or Program textarea with the line selected — line numbers refer to the saved data). No run picked up within 30 s (and no older one running) → "PDF-generatoren startede ikke". Polling never prompts for a password (`manusApi(…, {prompt:false})`); without one it falls back to `siteFileStatus` on `manus.pdf`'s `Last-Modified`. 10 min timeout, shown explicitly. On load, a failed last run turns the "Sidst genereret" line into "Seneste generering fejlede. Vis detaljer", and a run still going resumes the "Genererer..." state.

# Program tab (`data/program.json`, boss/admin) — printed programme booklet

Generates `archive/<folder>/Program.pdf` (front cover / Aktoversigt / Medvirkende / Ordliste / QR page(s) / back cover). The sixth Main Manus View tab, independent of `manusDraft` (not per-scene), with its own `programDraft` + `siteLoadOverride`/`siteSaveOverride` shadow. **Auto-saved, not part of Gem** (`programAutosave` → `programSaveNow()`): each save sends `baseSha` (from `program_read` or its own last save, which `save_program` returns); on a 409 it re-reads and merges per section (Medvirkende / Ordliste / QR-koder) against `programBase`. A section only they changed is pulled into the draft; one both changed shows a banner in that section ("Behold min" / "Brug deres", `programConflicts`) and waits while the others save. Status line at the top of the tab (`manusAutosaveStatusEl`).

- **Medvirkende**/**Ordliste** are each a single **raw-LaTeX** textarea (`\arb{Kategori}` headers, `\\`-terminated lines), inserted verbatim — not escaped, not sorted (ordering is the editor's job). **QR-codes** `{label, url}`: the PNG is generated at build time from `url` via `qrcode`, never stored; added via a centered "+" (`.boss-manage-add-plus`); only `label`/`url` are `texEscape()`'d. A QR row is saved only once it has a label and a valid (or empty) link (`programQrSaveable`); until then it lives in the draft only. QR rows are draggable but have no custom drag image/drop tail (the one exception to the drag convention below).
- `buildProgramSections()` sources Aktoversigt from `scenes.json` (centered `\Huge`, like the original hand-written `program.tex`, not `Aktoversigt.pdf`'s numbered layout) and **excludes the `E`/Ekstranumre act**. Front cover = the current production's Arkiv `coverImage`, falling back to `archive/_assets/placeholder-cover.jpg`; back cover is always that placeholder. The six pieces compile as separate PDFs (Medvirkende/Ordliste have unknowable page counts); `composeProgramPdf()` assembles `Program.pdf` in reading order and a reordered "booklet source" (front, Aktoversigt, Ordliste, Medvirkende, blanks, QR, back — see `imposeBooklet()`'s comment) padded to a multiple of 4, which `imposeBooklet()` imposes two-up on landscape A4 in saddle-stitch order: `ProgramHaefte.pdf` (vertical flip) and `ProgramHaefteHorisontal.pdf` (every back side rotated 180°). The booklet order is a fixed template sized for a normal year (two folded sheets), by product decision.
- Rebuilt by "Generér PDF'er" like the other PDFs. `data/program.json` must exist before the first save (no create-if-missing); if missing, `generate-pdfs.js` skips Program with a notice.
- **Not reset** by Koordinator's close-year: a new production inherits Medvirkende/Ordliste/QR as a starting point.
- Redskaber's **Program** page (`program.md`) is a separate, revyst-editable scratch copy of Medvirkende/Ordliste; nothing syncs between it and this tab (bosses copy by hand).


## Known issues & ideas

- **"Generér PDF'er" with an empty production** fails: with no scenes, Aktoversigt emits an empty `enumerate`, LaTeX rejects it (reported in the error modal; the merge steps are skipped). Fix: skip or placeholder empty acts.
- **Compile a video scene's manus into the PDFs**: `hasScript()` in `generate-pdfs.js` excludes `video` (bandsang is already compiled); the open question is which LaTeX environment to use (`revy.sty` has none for video; `sketch` is the obvious fallback).

**Override shadow**: `setManusSavedOverride()` in `manus-data.js` also writes `siteSaveOverride('manus', …)`, which Øveplan, Stjerneark and Ninjas read.
