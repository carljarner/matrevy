# Kalender (`kalender.html`/`calendar.js`, `data/calendar.json`, boss-level editing)

1200px-wide page. Month grid + list toggle (view persists in `localStorage`, defaults to list at ≤719px). List view shows only upcoming events, grouped by month. `category` is an ASCII key; `CAL_CATEGORIES` in `calendar.js` is the source of truth for label/order/color (duplicated in `embed-scenes.js`'s `.ics` builder). Multi-day events carry `endDate` (`>= date`); `calEventEndDate(ev)` is the one helper for "when does this end." A month-grid chip opens a read-only detail modal; boss/admin also get "Rediger" there. Date/time/category fields use the shared pickers.

- **`.ics` subscribe feed**: a static RFC 5545 file built by `embed-scenes.js` (`raw: true` entry), written by the worker to `/data/site/generated/calendar.ics` and served at `/calendar.ics`. Timed events are real UTC (`Z`) `DTSTART`/`DTEND` via `copenhagenOffsetMinutes()`/`icsUtcDateTime()` — a hand-coded, DST-aware Europe/Copenhagen offset (EU last-Sunday-of-March/October rule), no timezone library. Floating local times were misread as UTC by Google Calendar's URL importer, and a `TZID` + embedded `VTIMEZONE` attempt was also unreliable there; real UTC has nothing to mishandle. `X-WR-TIMEZONE:Europe/Copenhagen` is a harmless hint for other clients. All-day events use `VALUE=DATE` with `DTEND` one day past `endDate` (exclusive).
- **Revyperiode Gantt** (`data/gantt.json`, **admin** `gantt` resource, `renderGantt()`): second card, public to read (hidden while empty). Axis September–November of the stored `year`; admin-named rows, each with `{start, end, label, color}` bars (`color` one of six `GANTT_COLORS`, picked via swatches; falls back to a per-row cycle), positioned by percentage, clipped to the window, stacked into lanes on overlap. Hover shows `calShowTooltip` (label + date range). Admin edits an auto-saved `ganttDraft` (`ganttAutosave`; the head's pencil (`siteEditToggle`) becomes a check mark, which flushes and leaves edit mode, staying put if the save failed; status line `calPaintSaveStatus`; an empty row title blocks saving): rename/drag-reorder/remove rows (`calGetDragImageEl`, `.gantt-drop-tail`), click an empty track or a row's "+" to add a bar, click a bar to edit it. Changing the year offers to shift every bar.
- **Revyugen week schedule** (`data/revyugen.json`, **admin** `revyugen` resource, `renderRevyugen()`): third card, a Google-Calendar-style week view of the revy's final days (`startDate`–`endDate`, max 31 days; `startHour`–`endHour`). Revyst-level to read (hidden below admin while empty). Blocks are `{id, date, start, end, title, text, category}` — bold `title`, plain `text`, no timestamp (time range in the `calShowTooltip` hover); `category` is one of `REVYUGEN_CATEGORIES` (Øvning/Frivillig/Scenefolk/Obligatorisk/Andet → blue/green/yellow/red/purple, legend in the card head). `end` may be `"24:00"` (an entered end of `00:00` is stored that way). Overlapping blocks split the column (`revyugenLayoutDay`). Admin edits an auto-saved `revyugenDraft` (`revyugenAutosave`, same pencil/check toggle as Gantt): click empty space to add (snapped to 30 min), click a block to edit; moving "Første dag" shifts the whole period and every block, moving "Sidste dag" only changes the end. Blocks use `.revyugen-color-*`, styled like `.cal-chip`. Reuses `calCreateCategoryField` with an options list.
