# Øveplan (`schedule.html`/`schedule.js`)

Loads only `site.js` → `scenes-data.js` → `config-data.js` → `calendar-data.js` → `lokaler-data.js` → `fravaer-data.js` → `schedule.js` (no `site-utils.js`, no `manus-data.js`).

- **Manus gate**: below boss, `loadScenes()` loads no `scenes.json` scenes (only `CUSTOM_SCENES`; the cast roster stays) until Manus's "Revyster kan se manus" and "Revyster kan se roller" (`config.pdfLinksVisibleToRevyst`/`rolesVisibleToRevyst`, or their `matrevy-override-config` shadow) are both on (`schedManusVisible()`/`schedManusHidden`); sidebar and picker show "Manus er ikke frigivet endnu." or "Rollerne er ikke frigivet endnu." Cosmetic, like every read gate.

- Single global `state`: `{ rooms, slots, slotsConfig, grid, scenes, allScenes, allCast, absentees, title }` — `slotsConfig` = `{startTime, endTime, segmentMinutes, gapMinutes}` (defaults 25-minute segments, 5-minute "Pause mellem segmenter").
- `grid[slotIdx][roomIdx]` is `{ sceneId, customCast?, crossedOutCast?, customText?, customName?, pairedSceneIds? } | null` — only ids, never scene objects. `customCast` overrides a placement's cast; `crossedOutCast` marks people struck through in that cell; `customText`/`customName` are Scenemøde-only; `pairedSceneIds` are the other parts of the same scene merged into the placement (an older save has a single `pairedSceneId`; `schedCellSceneIds()` reads both).
- State persists to `localStorage['matrevy-schedule']` on every mutation (`saveState()`), restored by `restoreState()`. Any new mutation must keep this contract. Flush sequence: `renderGrid()` + `renderSceneSidebar()` + `saveState()`. No reactive framework — explicit render calls.
- **Scene data**: from `SCENES_DATA`; on a fresh session or after "Ryd skema", `loadScenes()` prefers Manus's `localStorage` override (`matrevy-override-manus`, with its own TTL) so a just-saved Manus change shows up in the same browser. Otherwise it reflects the embed on reload.
- Scenes are placed via a picker modal (multi-select fills empty rooms left-to-right; a single pick goes straight into the clicked cell), or by drag-and-drop from sidebar chips and between cells (swap; blocked drops highlighted). The picker tags "O" (role conflict) or "F" (absent) — advisory only. A scene with `repeat` can be placed twice before it dims (↻).
- **Priority** badges are read-only, each part's own Stjerneark field (`schedPartPriority`: Skuespil from `prioSkuespil`, falling back to the legacy `priority`); `null` (shown, nothing selected) is a grey 0 (`schedPriorityBadge`, `.prio-none`).
- `buildGrid()` preserves placements by matching rooms **by name**, so reordering/adding/removing rooms doesn't scramble them (a renamed room starts empty). Changing start/end/segment/gap fully resets the grid (`buildSlots(start, end, segment, gap)`); otherwise manually edited slot times are kept.
- **Custom scenes** (`CUSTOM_SCENES`, `custom:true`): `Scenemøde` (editable cast line/title) and `Rekvisitten` (no fixed cast — opens a full-roster checklist; chosen names become `customCast`). Both exempt from "already placed" dimming.
- **Scene parts** (`SCHED_PARTS`, `splitSceneParts()`/`applyScenePartSplits()` at load, runtime-only): every Stjerneark priority field a scene has (`prioSkuespil`/`prioSang`/`dansPriority`/`prioBand` present in `scenes.json` = shown in Stjerneark; a scene with none of them: Skuespil, plus Dans when `isDanceSplitCandidate`) becomes its own placeable part: Skuespil keeps the scene's id and title, the others are `<id>::sang`/`::dans`/`::band`, `"<title> (Sang)"` etc. Each part has its own priority and `defaultNames` (what `filteredCastNames` returns): Skuespil as the old main half (minus dancers when there's a Dans part; a song's singers + instruktør, a sketch's everyone but Statist/Ninja), Dans the dancers/koreograf/instruktør, **Sang** = Skuespil's minus the instruktører, plus the Sangboss (`schedSangbossName`, `cast.json`'s `sangboss` entry), **Band** = Skuespil's minus the instruktører and the Sangboss. All parts share `repeat`. The picker shows one row per scene (`.picker-scene-row`: title wide, then Sang/Dans/Band in fixed columns, empty where absent); the sidebar lists each part as a chip. Parts of one scene picked together merge into one placement (`collapseScenePartGroups()`: union cast, `pairedSceneIds`, one room toward the cap; Skuespil + Dans also takes the rest of the scene's cast but Statist/Ninja, as before), named `"<title> (Sang + Band)"` by `schedCellName()` (Skuespil + Dans stays just the title). The cell editor's Roller lists the whole scene's cast, plus the Sangboss right after the instruktør(er) for any scene with a Sang part (`getSceneCastWithRoles`).
- **Cast classification**: `ROLE_CATEGORIES`/`classifyRoleCode`/`classifyOrKeep` live here (moved from the removed `import.js`). **Always call `classifyOrKeep`.** Displayed and conflict-checked cast both use the filtered list (`getCellCastNames` → `filteredCastNames`, hiding Statist/Ninja; an unmerged song/dance placement narrows to its categories), skipping crossed-out people; a `customCast` is returned verbatim.
- **Per-cell cast editor**: "Roller" (open by default) and "Andre revyster" (closed; open by default for Rekvisitten). A Roller row toggles crossed-out (`(overstreget)`). Busy/absent rows show a suffix and are disabled-but-removable.
- **Absences**: `state.absentees` = `{name, start, end}[]` (minutes since midnight). `isPersonAbsentAtSlot(name, slotIndex)` is the single source of truth (grid styling, "F" tag, editor). An absent person is exempt from conflicts for that slot.
- **Opmærksomhed** (`computeAttentionLists`/`renderAttentionSection`): lists of people needing attention, split at 13:00; hidden in print.
- **Merging/splitting slots** lives in the per-slot time editor (`openSlotTimeEditor`/`renderSlotTimeEditor`): "Flet (op)"/"Split"/"Flet (ned)" above Start/Slut. Merging (`mergeSlots(si)`, enabled only when `canMergeSlots(si)` — no room occupied in both) spans the earliest start to latest end, keeps whichever placement exists per room, and closes the modal. "Split" (`slotTimeMode`) shows two editable Start/Slut rows seeded from `defaultSplitMid()`; "Opdel" (`confirmSlotTimeEditor` → `splitSlot`) keeps placements on the first half.
- **Lokalebooking button** (on the "Lokaler (ét per linje)" line, `openLokalebookingModal()`): a modal of day columns, each listing the rooms booked that day in Koordinator's Lokalebooking (non-blank cells, sheet order; a cell's text other than "x" shown as a note), scrolled to today/the next day. "Hent" **replaces** `#input-rooms` with that day's rooms and `saveState()`s (no rebuild — "Byg øveplan" still does that). Day columns are `schedLokalerDays()`, a copy of Koordinator's `koordLokalerDays()`; data prefers the `matrevy-override-lokaler`/`-calendar` shadows (`schedLoadOverride`), else `LOKALER_DATA`/`CALENDAR_DATA`. Built on `schedOpenDayStripModal()`, shared with:
- **Fravær button** (on the "Fraværende revyster" line, `openFravaerModal()`): the same day strip listing Koordinator's Fravær sheet (`FRAVAER_DATA` or the `matrevy-override-fravaer` shadow) per day — name + cell text. `schedParseAbsenceText()` reads a cell (`14:00 - 16:00`, `14-16`, `1430-1600`, `fra/efter 15`, `til/indtil 13`, `x`/`hele dagen` = the Start/Slut fields' day); names match `state.allCast` case-insensitively. Unknown names and unreadable times are shown in red and left out. "Hent" **replaces** `state.absentees` with that day's absences (undoable with Ctrl+Z).
- The grid title (`#sched-grid-title`) is `contenteditable`, stored in `state.title`. "Ryd skema" wipes only `state.grid`.
- **Undo/redo** (`schedUndo`/`schedRedo`): `saveState()` calls `schedUndoRecord()`, which pushes the previous whole-state snapshot (`schedUndoSnapshot()`: rooms, slots, `slotsConfig`, grid, absentees, title + the day-setup fields) whenever the state changed — so every mutation that keeps the `saveState()` contract is undoable for free. In memory only (max 20 steps, reset by `restoreState()` on load). Applying a snapshot re-renders (incl. the empty state when undoing the first build) and persists without recording. Keyboard only: Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z or Ctrl+Y outside text fields/modals (inside a field the browser's text undo wins); no buttons, by decision. The Byg/Ryd confirms say it can be undone.
- `escHtml()` is the sanitizer for this file's `innerHTML` templates — always use it when interpolating.

**Print** (`@media print` in `schedule.css`, via "Download" → `window.print()`): deliberately plain black/white "typewriter" style (Courier New, ruled borders, `@page { size: A4 landscape }`, 12px base), fixed-width columns, flexible rows, Opmærksomhed hidden. `@page { margin }` is unreliable (Safari) — real in-flow padding guarantees the whitespace.


## Ideas

- **Auto-place**: implemented once, removed for a redesign. Spec: greedy placement by priority respecting cast conflicts and absences, auto-placed cells visually distinct, re-runnable, with a summary.

**Own styles**: `schedule.css` keeps the pre-theme look with its own `.btn-primary`/`.btn-secondary` and `.picker-selected` (literal `#d8b879`); its "Ryd skema?" confirm uses the shared `.login-overlay`/`.login-actions`/`site-btn-*`. Hover-only reveals have a `@media (hover: none)` fallback (`.cell-remove`). Øveplan is revyst-level because it never writes through the server (placements live in `localStorage`).
