# Teknikken (`teknikken.html`/`teknikken.js`/`teknikken.css`) — the tech crew's file store

A Drive-like nested folder tree for videos (.mov/.mp4), slides (.pptx), images and any other file type, **capped at 5 GB for the whole store** (`teknik_quota_bytes()` ↔ `TEKNIK_DEFAULT_QUOTA_BYTES`; no per-file limit), with a usage bar centred above the card (`X af 5 GB brugt`). Revyst-level page under Redskaber, fully open at revyst+ (anyone creates/renames/moves/deletes anything). Private data in `TEKNIK_DATA_DIR` (`/data/teknikken`): `teknikken.json` = `{folders:[{id, name, parentId}], files:[{id, folderId, name, ext, size, crc32, uploadedAt, uploadedBy}], updatedAt}` (`null` parent = the top level), bytes at `files/<fileId>` (name is metadata only), in-progress uploads at `uploads/<uploadId>.{part,json}` (swept after 24 h). **One store for the whole site, not per revy, and never archived or mirrored** — files are temporary (the page says so); excluded from the restic backup. Koordinator's Arkivering guide tells people to download what they want ("Download alt") before **Afslut revyen** clears it (`teknik_clear_all`). **Uploads are closed while no revy is active** (`currentProductionFolder` empty, `teknik_uploads_open()`): `teknik_upload_start` and `teknik_upload_finish` answer `409 uploads_closed` (finish also discards the part, so an upload started before Afslut can't land in the emptied store), and `teknik_read` returns `uploadsOpen`, which disables the upload buttons and desktop drops and shows a notice. "Ny Revy" opens them again. A boss can also **pause uploads for everyone** (bosses included) from the **Boss Box** card at the bottom of the page (boss/admin only, `teknikBuildBossBox()`: one "Åben for uploads" switch) → `config.json`'s `teknikUploadsClosed` (boss `config` resource); `teknik_uploads_open()` is then false, the two upload actions answer `409 uploads_paused` (vs `uploads_closed` for no revy) and `teknik_read` also returns `uploadsPaused` and `revyActive`, so the notice says which. Koordinator's Afslut sets it `true` (locked until Ny Revy, which sets it `false`). Online-only.

- **Tree**: folders open/close in place like Bandet's Noder (open set in `localStorage` `matrevy-teknik-open`), contents indented by `--depth`; folders first, then files, Danish-alphabetical. A folder row shows its direct contents; deleting one confirms with the recursive count and removes the whole subtree + bytes (`teknik_delete_folder`, idempotent). Folders can't be moved (only renamed).
- **Moving files**: drag a file row (`teknikGetDragImageEl()` ghost) onto a folder row, onto a row inside an open folder (→ that folder) or anywhere else on the card (→ the top level), all via one handler on the card (`teknikWireDrop`/`teknikDropTarget`, rows carry `data-target`) → `teknik_move_file`. The file's edit modal ("Rediger fil": Navn + Mappe) also moves it — the touch-screen path.
- **Card head**: "Filer" | "+ Mappe" (centred, a `1fr auto 1fr` grid) | "Upload filer" + "Upload videoer" (equal widths, `.teknik-upload-btns`).
- **Upload filer** (`teknikOpenUploadModal`): every non-video upload — the button or files dragged in from the desktop (preselecting the folder they were dropped on). Videos (`teknikIsVideo()`, the `video` kind's exts) are skipped with a toast pointing to Upload videoer; a desktop drop of exactly one video opens the video modal instead. The modal asks **Afsender** (required free-text name, remembered in `localStorage` `matrevy-teknik-uploader`, stored as `uploadedBy` and shown in the file row's meta line; not asked for folders), a name per file (prefilled with its own name, extension kept, like Bandet's upload modal) and "Upload til" (top level or any folder); it refuses a batch bigger than the free space (`teknikFreeBytes()`, which counts this tab's queue too).
- **Upload videoer** (`teknikOpenVideoUploadModal`): opens the modal first; Afsender, a video file, the project as one `.zip` and a Navn are all required (+ Upload til). Uploaded as two ordinary files, `<Navn>.<videoext>` and `<Navn> (projektfil).zip`, same `uploadedBy`.
- **Chunked upload** (php.ini caps a request at 25 MB, so Bandet's one-base64-JSON upload can't carry big files): `teknik_upload_start {folderId, name, uploadedBy, size}` (`413 quota_exceeded` when files + every upload in progress + `size` passes the quota — checked and reserved under `uploads/.lock`, so simultaneous starts can't both fit; `507 disk_full` unless `size` + 2 GB stays free on disk) → `teknik_upload_chunk {uploadId, offset, contentBase64}` (≤8 MB raw, strictly appended at the `.part`'s current size; an already-written chunk answers ok, a gap answers `409 bad_offset` with `received`, which the client resumes from) → `teknik_upload_finish` (size check, rename into `files/`, stores `crc32`, 404 if the folder was deleted meanwhile) / `teknik_upload_abort`. The client uploads one file at a time from a queue (`teknikQueue`, upload panel with progress bars and ✕), retries a chunk on network/5xx errors with backoff, and warns on `beforeunload`/`siteRegisterUnsavedCheck` while anything is queued.
- **Signed downloads** (the browser downloads natively — no blob in memory): `teknik_download_url {fileId, inline}` / `teknik_folder_download_url {folderId}` (null = everything — "Download alt", bottom right of the card) return `teknik_dl=<payload>.<HMAC-SHA256>` valid 10 min, keyed on the three passwords (new passwords void old links). The GET branch streams a file with single-range support (206, video seeking), `nosniff`, `attachment` unless `inline` was asked for an allow-listed type (`teknik_inline_types()` ↔ `TEKNIK_INLINE_EXTS`: pdf/images/mp4/mov/audio — never SVG/HTML). A folder comes as a **.zip streamed on the fly** (`teknik_serve_zip()`): stored, not compressed, every CRC (saved at upload; computed for older files) and size known up front, so nothing is buffered or written to disk and the exact `Content-Length` is sent; ZIP64 records only when an entry or offset passes 4 GiB; one top directory named after the folder (or "Teknikken"), empty folders included, clashing names get " (2)". Downloads go through a hidden iframe (no navigation → no unload warning mid-upload); inline types open in a tab opened synchronously in the click; iOS navigates in place.
- **Server actions** (`$TEKNIK_ACTIONS`, all revyst): `teknik_read` (+ `quotaBytes`), `teknik_create_folder`, `teknik_rename_folder`, `teknik_delete_folder`, `teknik_rename_file`, `teknik_delete_file`, `teknik_move_file`, `teknik_upload_start`/`_chunk`/`_finish`/`_abort`, `teknik_download_url`, `teknik_folder_download_url`; admin `teknik_clear_all` (empties the whole store, idempotent). `teknik_mutate()` = flock'd copy of `kostume_mutate()`; hoisted functions, no consts (dispatched early).
