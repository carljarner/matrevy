# Ninjas, Mics & Cues (`ninjas.html`/`ninjas.js`/`ninjas.css`) — mic plan + cue sheet

Revyst-level page under Redskaber with three tabs styled like Bandet's (`.ninjas-mode-tabs`, a copy of `.band-mode-tabs`; active tab in `matrevy-ninjas-tab`, default Mikrofonplan): **Ninjaplan** (placeholder card), **Mikrofonplan** (replaces the old Mic-plan spreadsheet) and **Cues** (replaces the old Cueark). Private data (names per scene) in `NINJAS_DATA_DIR` (`/data/ninjas`): `<folder>/ninjas.json` = `{mics:[{id, name, label, color}], micCells:{<rowKey>:{<micId>: text}}, cues:{<rowKey>:{instruktoer, startCue, giverCue, slutCue, note}}, extraRows:[{id, act, afterKey, title}], updatedAt}`. One document per revy, with Kostumetinder's picker and folder rule (`ninjasRevyOptions()`, `matrevy-ninjas-revy`; revyster edit only the current production, `ninjasCanEdit()`; on an older year below boss the Rediger button is hidden, so the sheets stay in read mode). Online-only.

- **Rows come from Manus**, not the document: `ninjasBuildGroups()` groups `SCENES_DATA` (or a fresh `siteLoadOverride('manus')`; for an older year the `archive/<folder>/snapshot/scenes.json` Koordinator's Afslut saves, `ninjasLoadSnapshot()`, flattened like `embed-scenes.js`; no snapshot → "Der er ingen scener gemt for denne revy.") by act code (the `id` prefix; `pool` skipped), in Manus order. Videos and band jingles get no row (`ninjasSceneIsMedia()`, Manus's `manusRowIsManualMedia` rule on `types`); an extra row placed after one moves up to the row before it. A cell is keyed by the scene's `rowKey` = `uid || 'id:'+id` (same as `manusSceneUid()`; a uid is `s…`, or `sub:<submissionId>` for a scene chosen from the upload pool — `ninjas_valid_row_key()` must accept every form), so it follows its scene through moves and renames. Cells of scenes no longer in Manus stay in the file, unseen. **Extra rows** (Bandintro, …) are the only hand-made rows: per act, placed after `afterKey` (`null` = first in the act; an unknown key = last), `rowKey` `x<id>`, shown in both tabs (italic title), edited in a modal opened from the act heading's "+" or the row's title (Titel, Placering, Slet). Deleting one hands its spot to rows placed after it.
- **Manus gate**: below boss the current production lists nothing until `pdfLinksVisibleToRevyst` and `rolesVisibleToRevyst` are both on (like Øveplan's `schedManusVisible()`); older years always show. Cosmetic.
- **Edit toggle**: each sheet has its own pencil/check (`siteEditToggle`) in its card's top-right corner (`ninjasCardHead()`, state per tab in `ninjasEditing`, read via `ninjasIsEditing()`; off on every load and turned off when you switch tab). It is UI only — every revyst+ can write.
- **Print**: each sheet's card head also has a centred Print button (`ninjasPrint()`): it re-renders the sheet in read mode (`ninjasPrinting` makes `ninjasIsEditing()` false), calls `window.print()`, and restores edit mode on `afterprint`. `@media print` in `ninjas.css` prints only that card on **A4 landscape** with black ruled lines (`print-color-adjust: exact`); Mikrofonplan cells take their mic's full header colour, like the old Mic-plan sheet, with the names in bold. Both printouts break the page before Akt 3 (`NINJAS_PRINT_BREAK_ACT` → `.ninjas-print-break`), so Akt 1-2 fill page one and Akt 3 + Ekstranumre page two; the header row repeats. On screen the header row follows the page instead (`siteStickyHead`). Read mode is a plain table; edit mode puts inline-style inputs in the cells.
- **Live, cell-granular writes**: a cell commits on blur/Enter (`ninjasCommitCell`, chained per cell in `ninjasCellChains`, sent to the revy it was typed in; `ninjasPending` (`cellId → {folder, value}`) is re-applied over any full-document response; `siteRegisterUnsavedCheck` + `beforeunload` while pending). One cell per request, so people editing different cells never collide. A failure reverts the cell; a `409` re-reads.
- **Mikrofonplan**: one column per mic. The header is in the mic's colour (`NINJAS_COLORS` ↔ `ninjas_colors()`, `.ninjas-color-<key>`) with an optional tape `label` ("Gul/Hvid"); filled cells get a light tint. A cell is free text ("X", a name, "(kun i intro)"). A suggestion popup (`ninjasWireSuggestions`, `.site-field-pop` + `.site-list-row`, arrow keys + Enter) offers the scene's cast minus whoever already has a mic in that row. The same cast member on two mics in one scene marks both cells `.ninjas-cell-warn`. In edit mode a header click opens the mic modal (Navn, Mærkat, colour swatches, Slet), the trailing "+" header adds one, and headers drag to reorder (`ninjasGetDragImageEl`, the "+" header is the drop tail) — all via the full-replace `ninjas_save_mics` (a removed mic's cells go with it). A document that doesn't exist yet reads as the old sheet's 14 mics with deterministic ids (`ninjas_default_mics()`).
- **Cues**: scene title (sticky, no heading — same in Mikrofonplan) | Instruktør | Start cue | Giver cue | Slut cue | Bemærkninger, auto-growing textareas in edit mode (Shift+Enter = new line). **Instruktør is read-only and derived from Manus** (`derived: true` in `NINJAS_CUE_COLUMNS`): the scene's cast members with the Instruktør role (`ninjasIsInstructor()` — `tags` first, then the classified `role`, then a raw code containing `I`), comma-joined; empty on extra rows. A stored `cues[*].instruktoer` (from before) is ignored. No per-instructor colours (removed by request). Start cue suggests Lys/Band/Lyd/AV.
- **Server actions** (`$NINJAS_ACTIONS`, all revyst + the folder rule): `ninjas_read`, `ninjas_set_mic_cell` (micId must exist, else `409 stale_mics`), `ninjas_set_cue`, `ninjas_save_mics`, `ninjas_upsert_extra_row`, `ninjas_delete_extra_row` (idempotent, also clears its cells). `rowKey` is validated against `ninjas_valid_row_key()`. `ninjas_mutate()` = flock'd copy of `kostume_mutate()`; hoisted functions, no consts (dispatched early).
